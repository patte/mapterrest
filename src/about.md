# Mapterrest

Open-source, fullscreen, 3D map viewer combinding multiple of free or gratis map resources and techniques.

This project started when I had the idea of combining the globally available elevation model [GLO-30 from Copernicus](https://portal.opentopography.org/raster?opentopoID=OTSDEM.032021.4326.3) with more detailed local models. And to my not surprise but delight somebody had already done it, and properly: [Mapterhorn](https://mapterhorn.com/) offers freely available PMTiles, so cool! I wanted to see how it looks rendered in 3D with different tiles on top. And I wanted to see a heatmap of the global terrain. I found that quite interesting: you can spot the Rhine without any labels! And who knew how flat the Po Plain really is?! Things kind of escalated from there...

I noticed that there are many interesting map resources and techniques around, but they are often showcased in small example viewers or have clunky controls, and they are scattered across many websites. So I set out to combine what I found interesting in this simple, fullscreen viewer. You can read detailed docs in the [repo](https://github.com/patte/mapterrest#docs). The code is open source and contributions are welcome. Feel free to open an issue for questions, feature requests, bug reports or criticism.

Big thanks to all geospatial contributors for making it possible to see the world in all these interesting ways!
